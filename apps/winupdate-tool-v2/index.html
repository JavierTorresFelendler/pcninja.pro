What it does

  • Lets you choose which updates to install, a choice Windows Update itself took away in recent years. Leave one out for a while, for example to test after a problem; Windows will offer it again later.
  • Checks, installs and schedules updates, audits drivers and can reset a stuck update service.
  • Use it when a PC won’t update on its own, or to speed up a technician’s work.
  • MSI for deployment or a portable EXE. Updates itself after verifying the download.

What carried into WinTool

  • Choosing which updates to install
  • Scan, preview and install, rewritten in C#
  • Scheduled runs with retry, wake-to-run and run-if-missed
  • Restart handling, health check and reset
Moving to WinTool?

WinTool finds this tool, offers to import its schedule and removes it, so two tools never update the same PC.
