Why I built it

Each of my tools had its own window, its own logs, its own updater and its own installer. One app writes all of that once, and a PC gets one tool instead of three.

How it grew

Looking ahead

The next step is some form of management for personal, home and small-organization environments, at the lowest cost possible.

The goal: a clear view of the health of every computer in the “organization”, and real control over it. I’ll be testing options like that in my home lab soon.

What it does

  • One EXE: run it portable or install it, even offline. The MSI is there for silent deployment.
  • Windows Update: scan, install, scheduled runs, restart handling.
  • Windows Upgrade: in-place upgrade from an ISO or Microsoft’s media, with checks before it starts.
  • Office: Microsoft 365 or Office LTSC 2024, Visio and Project; install, offline package, remove.
  • Logs, useful links, and a self-update that asks first. English, Hebrew and Spanish; follows Windows dark or light.
Coming from an older tool?

WinTool finds WinUpdate Tool V1 or V2, offers to import the schedule and removes the old tool, so two tools never update the same PC.

Files are not code-signed; Windows SmartScreen may warn. Check them against SHA256SUMS.txt.
