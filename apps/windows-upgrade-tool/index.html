Why I built it

With time came upgrade season. I already knew how to install Windows clean while working around Microsoft’s stricter hardware rules, but upgrading in place was always the hard part. That’s how Windows Upgrade Tool was born.

Over the years I learned Microsoft’s less documented ways of upgrading existing systems in place. Safe to say I got the hang of it, and the tool’s abilities grew with it.

I’ve been working with Windows since the happy days of XP, and I finished my Microsoft systems engineer studies shortly after Server 2003 came out. Over the years I kept sharpening one craft: building custom Windows images. And honestly, what Windows really needs from a PC hasn’t changed much since Vista.

Alongside that, I’ve always been the technician of whatever community I lived in. My rule is simple: when life is good to you, that’s the time to give back. So I try, sincerely, to keep the hardware people already have and to save them every cost I can, above all for those who can least afford a new computer.

What it does

  • Guides an in-place upgrade to Windows 10 or 11 on x64 PCs, including older hardware, from an ISO or Microsoft’s media.
  • Shows the current Windows version, storage and source choices on one screen. Portable, with a GUI and a command line.
  • The Windows 11 path for unsupported hardware is experimental. Back up your files first.

What carried into WinTool

  • The same upgrade engine, ported to .NET Framework 4.8
  • Every check before Setup starts: media, edition, language, storage
  • Command-line upgrade with WinTool’s exit codes
