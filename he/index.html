WinTool by PcNinja v1.0.2 חדש

אפליקציה אחת ל-Windows Update, לשדרוג Windows ול-Office. מריצים אותה כניידת או מתקינים מאותו קובץ EXE; ה-MSI זמין להפצה שקטה. באנגלית, עברית וספרדית.

הורדה עוד על WinTool קוד מקור

הקבצים אינם חתומים דיגיטלית, ולכן Windows SmartScreen עשוי להזהיר. בדקו אותם מול SHA256SUMS.txt.

  • Windows Updateסריקה, התקנה, תזמון וטיפול באתחולים. צמח מתוך WinUpdate Tool.
  • שדרוג Windowsשדרוג במקום, עם בדיקות לפני שמתחילים. צמח מתוך Windows Upgrade Tool.
  • Officeהתקנה, חבילה לא מקוונת והסרה. צמח מתוך Smart Office Installer.

איך הגענו לכאן

אני בונה Windows עוד מימי ה-XP העליזים. כל הכלים כאן נולדו מרעיון אחד: להשאיר אצל אנשים את החומרה שכבר יש להם ולחסוך להם כל עלות אפשרית. מהחדש לישן; לכל שלב יש עמוד משלו.
